## 一、女主：萧雁回（正派大小姐 · 明）

### 基本信息
| 项 | 值 |
|---|---|
| 姓名 | **萧雁回**　字：清殊　江湖号：**青鸾** |
| 身份 | 峨眉派掌门独女（峨眉 `emei`，蜀中，显正） |
| 年龄 | 20　家在蜀中萧氏，身宗门正派 |
| 外貌 | 眉目疏朗、明丽端方；青白道袍外披半段红绢（掌门之女信物）；腰悬「青霜剑」，发间一支白玉簪 |
| 武功 | 身法「逐云」+ 剑法「青霜」（正道剑，续航破招），气质/清心流；与男主天命剑、女二双匕互补成金三角 |
| 社会身份 | 峨眉掌门独女，下一代掌门候选（名门大小姐） |

### 性格
- 浩然清明，仁义（正道）与个人（人）之间以「认人不认派」为尺度。
- 明烈干脆：遇小人先拔剑，遇旧人先笑；大雅不虚。
- 重情重诺：男主在她面前是「死于万劫深渊的人」——她从不为他吊，剑为之而存。
- 心结：家道世族的「体面」与她自幼的「婚约枷锁」——她曾代为拒婚，这是她唯一的任性。
- 厌恶背叛（深层痛点：沈清寒一者一剑触发其底线）。

### 定位
对比男主（暗·火）、女二（刀·冷），她是「光·理」。存在意义：让他相信「道可同仇」。

### 弧光（五幕）
1. **归雁·雾中认故**（重逢）：男主以假名现身蜀/长安时重逢，她认剑不点破，客栈留白玉簪。
2. **明火·暗行**（双线收拢）：黑鸦对峨眉之仇与女二对剑；她救男一，但面对男主三年「以杀为道」为此冷下脸：『我认的由你说的理，不是你手里的刀。』——男主为自证"道"，两人正心经起。
3. **明剑·接班之劫**（她自我成长）：峨眉掌门垂老年，派内争位、以「名分」逼她联姻；她当众拒婚、拒为嫁妆、立守门派。背井川县险中与男主相认同行：「你说的复仇，和我要的正道，是同一条路。」
4. **断案·家丑**（真相与道德试剑）：幕后主使揭出——黑鸦无主，正是峨眉隐居长七、她师门长辈「玄霄子」；他那、沈清寒只是其一下的棋。她面对师门与大道，最终大义灭亲、正对上山。与女二从对剑走到并肩。
5. **归心·华山之巅**（大决战+她自证）：开篇「万劫深渊」呼应，她以「你教我的那一剑」替男主挡下穿胸一击。结局多野分线（见结局）。

### 结局三档
- 正途+好感高：成亲/夫妇并肩走江湖，双剑同立。
- 侠友道：她任峨眉掌门，每年大雪与男主对剑半宿。
- 黑线/好感低：华山之巅与男主对剑而别，各自天涯，仅剩一段青瓷残簪。

## 三、女二苏青秋（黑鸦第一杀 · 血凤）

### 基本信息
| 项 | 值 |
|---|---|
| 姓名 | **苏清秋**　代号：**血凤**（黑鸦第一杀手，行七，故称「七娘」） |
| 身份 | 黑鸦组织第一杀；蜀中唐门旁支，被沈清寒收养、淬养七年 |
| 年龄 | 20 |
| 外貌 | 肌肤白如新雪、眉眼清寒；黑发高束，鬓边一绺白发（「玄凰寒毒」淬身之印）；用**双刃「凤翎」**（淬毒），从不使剑 |
| 武功 | 身法「暗行无影」+ 刃法「凤翎」，贴身快攻单体爆点；偏根骨/气质流 |
| 武功反噬 | 「玄凰寒毒」限命——为弧光（Ⅳ幕）埋点 |

### 性格
- 外冷内热；重诺轻死；口不对心、毒舌护短。
- 只信手握的刀与她自己选的人；不信公道，但认「欠」—恩情要还、仇要还。
- **心结**：从不使剑——「剑为君子道，我不配。」（自我厌恶，为弧光破题）

### 弧光（五幕）
1. **拔刀相**（启）：剿四山后，沈清寒遣「血凤」若要男主的命。照面时她见她原仇（父/同门死于华山那剑），留一线而后。
2. **破·弃身**（揭心）：沈清寒设计以她一命为死局，却目睹沈为军师一把刮；她破「第一杀」之名为你挡剑，叛出明道——
3. **并肩·入队**：携静组织地图残页找男主补上主线盲区；遂 `_grantCompanion('苏清秋')` 入队；解锁她的「寒毒」身世（命数被毒拖住）。
4. **真相**：「黑鸦」是真主乃「玄霄子」；「凤翊」淬毒已渡男主如何暗——她须续命。
5. **归位**：终局（可由男主好感高低、正邪）：
   - 满意+正道：她以「剑客」入世，将双刃弃、食之剑，与你并行终身（可纳可婚）。
   - 邪路：她接黑鸦残部自成一派，与你对剑而终。
   - 中立：隐入山门、雪夜檐外放一柄新剑与黑羽吊坠相谢。
