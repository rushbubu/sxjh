## 男候四至（男子丁丁四种状态）
1. **充血发红** — 气血初动
2. **红而大** — 气血充盈
3. **大而挺** — 气血刚劲
4. **挺而热** — 气血至盛

## 女达五欲（女子五种生理反应）
1. **气上面热** — 面上发热
2. **咪竖鼻汗** — 乳尖竖起、鼻尖出汗
3. **舌薄而滑** — 舌头变薄滑润
4. **下沙股湿** — 阴液流出、大腿湿润
5. **嗌干咽唾** — 咽喉干燥、吞咽口水

## 青楼妓院等级与规矩

### 等级划分
- **一、二等（高级）** — 名号称"院""馆""阁"。名妓出手阔绰，呼奴唤婢，挥金如土。近官者富。
- **三、四等（低级）** — 名号称"室""班""店""下处"。妓女备受摧残剥削，不分昼夜接客，带病接客，稍有不从则打骂罚跪，重则贩卖乡下。

### 经营角色
- **龟头**（男老板）— 另配女"领家"管训导、督促接客、监督账目
- **老鸨**（女老板）— 副手为其男人或姘头，称"鱼公"，负责排解纠纷、对外联络
- **龟爪子**（跟班）— 负责监视妓女一举一动

### 清规戒律（八大不准）
1. 不准逃跑
2. 不准热客（冷落客人）
3. 不准甩客（拒绝客人）
4. 不准接官场、窑皮子（特殊客人/地痞）
5. 不准"开盘"时"偷活"（私下留客）
6. 不准私藏钱
7. 不准倒贴热客（倒贴喜欢的客人）
8. 不准犯"八大块"（说丧气话）
